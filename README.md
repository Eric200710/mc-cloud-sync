# Minecraft Cloud Sync (雲端存檔接力同步系統)

這是一個專為 Minecraft 玩家設計的**輕量化、免 24 小時伺服器**的「雲端接力存檔系統」。
讓好友間想玩就玩，並透過 Google Drive 進行存檔同步與「防衝突鎖定（Lock）」。

---

## 📦 專案結構

- `init_setup.bat` / `init_setup.ps1`：**【檔案 1】新手初始化安裝腳本**
  - 自動偵測系統是否安裝 Google 雲端硬碟電腦版（未安裝則自動引導下載安裝）。
  - 自動偵測使用者的 Minecraft 目錄並寫入 `config.json`。
  - 設定 Google 雲端硬碟共享目錄。
- `sync_world.bat` / `sync_world.ps1`：**【檔案 2】World 存檔同步腳本**
  - 啟動後直接提問：`[1] 下載檔案` 或 `[2] 上傳檔案`。
  - **防覆蓋機制**：當有人下載並在遊玩時，雲端會標記 `[遊玩中]`，其他人無法覆蓋。
  - **安全防護**：每次下載與上傳前，均會自動備份本地舊檔與雲端上一版舊檔。
- `config.json`：存放當前客戶端路徑與世界名稱設定。

---

## 🚀 如何分享給朋友使用（快速上手指南）

### 【第一步：建立共享 Google Drive】
1. 在你的 Google 雲端硬碟中建立一個資料夾（例如 `MC_Shared_Server`）。
2. 在該資料夾點選右鍵 -> **共用** -> 新增你朋友的 Google 帳號。
3. 確保大家都有安裝 [Google 雲端硬碟電腦版](https://www.google.com/intl/zh-TW/drive/download/)，此時大家的電腦都會有虛擬磁碟 `G:\我的雲端硬碟\MC_Shared_Server`。

---

### 【第二步：朋友安裝與初始化】
1. 將本專案（可直接以 ZIP 或 GitHub 倉庫形式）傳給朋友。
2. 朋友雙擊打開 **`init_setup.bat`**：
   - 依照提示安裝 Google Drive（若已安裝會自動跳過）。
   - 程式會自動探測他的 Minecraft 路徑並保存。

---

### 【第三步：平時遊玩流程】
每次想玩 Minecraft 時：
1. 雙擊打開 **`sync_world.bat`**。
2. **開玩前**：輸入 **`1`**（下載檔案），系統會抓下最新存檔並在雲端標記為「遊玩中」。
3. 打開 Minecraft 啟動器進遊戲遊玩。
4. **玩完後**：在遊戲內「儲存並退出世界」，完全關閉遊戲。
5. 回到 `sync_world.bat`，輸入 **`2`**（上傳檔案），系統會自動壓縮打包上傳，並解除鎖定，讓下一個朋友隨時接力！
